# @workspace/admin-dashboard

Next.js 15 admin UI (App Router, Tailwind 4, dark-mode-ready).

## Routes (`src/app/`)

| Route | Feature |
|-------|---------|
| `/login` | JWT login |
| `/` | Dashboard KPIs + charts |
| `/products` | CRUD, variants, images |
| `/categories` | Hierarchy, images |
| `/customers` | Search, block, B2B pricing |
| `/pricing` | Customer-specific prices |
| `/promotions` | Coupons, flash sales |
| `/orders` | Status, refunds, invoices |
| `/inventory` | Stock, warehouses, logs |
| `/settings` | VAT, roles, audit |

**Step 1:** scaffold only. UI built in Step 8.
